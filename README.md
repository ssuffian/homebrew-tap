# Homebrew tap

Install Toddler Keys (Apple silicon or Intel, macOS Ventura or newer):

```sh
brew install --cask ssuffian/tap/toddlerkeys
```

Launch **Toddler Keys** from Applications. Quit the app before updating:

```sh
brew update
brew upgrade --cask toddlerkeys
```

Updates are applied when you run these commands. The app does not update itself in the background. The cask is updated by the app’s Mac publishing command after both signed, notarized downloads are uploaded.

Source and releases: https://github.com/ssuffian/toddlerkeys
